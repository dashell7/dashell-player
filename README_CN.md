# LangPlayer (LinguaFlow) - Obsidian 终极语言学习播放器

[![版本](https://img.shields.io/badge/version-1.6.0-blue.svg)](https://github.com/dashell7/obsidian-langplayer)

LangPlayer 是一款专为 Obsidian 用户打造的沉浸式语言学习工具。它将视频播放器、智能字幕系统和笔记工具无缝集成，助您将任何视频转化为强大的语言学习材料。

## ✨ v1.6.0 核心亮点

### 🎬 强大的媒体播放器
- **全格式支持**：MP4, MKV, WebM, MP3, WAV 等主流音视频格式。
- **多源加载**：支持 Vault 本地文件及 Bilibili/YouTube 等在线视频。
- **智能布局**：
  - **底部/右侧布局**：灵活切换字幕位置，适应不同学习场景。
  - **即时填充**：Contain/Cover/Fill 模式切换即时生效，无需重启。

### 🌐 智能多语言字幕系统
- **自动加载**：自动查找并加载同名 `.srt` 或 `.vtt` 字幕（支持 `.zh.srt` 等后缀）。
- **多语言切换**：全新的语言选择菜单，自由组合显示/隐藏多种语言字幕。
- **交互体验**：
  - **自动滚动**：字幕随播放滚动，鼠标悬停时智能暂停。
  - **整行/逐字高亮**：像卡拉OK一样精准跟随。
  - **点击查词**：集成查词功能，点击即查。

### 📝 深度学习辅助
- **沉浸式笔记**：
  - **一键插入 (`Ctrl+I`)**：将当前字幕（纯文本+时间戳链接）快速插入笔记。
  - **智能跳转**：点击笔记中的时间戳，视频即刻跳转并自动播放。
  - **自动分屏**：打开笔记时自动在播放器右侧分屏，打造完美学习工作台。
- **听力训练**：
  - **单句循环**：无限重复当前句子，攻克听力难点。
  - **AB 复读**：自定义任意片段循环。
  - **影子跟读**：智能暂停模式，留出时间供您跟读模仿。

## 🚀 快速开始

### 1. 安装
在 Obsidian 社区插件市场搜索 **"LangPlayer"** 并安装。

### 2. 准备素材
将视频文件（如 `movie.mp4`）和字幕文件（如 `movie.srt`）放入 Obsidian 的同一个文件夹中。

### 3. 打开播放器
- **右键菜单**：右键点击视频文件 -> "Open with LangPlayer"
- **命令面板**：`Ctrl/Cmd+P` -> "LangPlayer: Open Media Player"
- **侧边栏**：点击左侧的 "Play" 图标

### 4. 开始学习
1.  **调整字幕**：点击控制栏的语言按钮，选择适合您的语言组合。
2.  **记笔记**：听到金句或生词，按 `Ctrl+I` 插入笔记。
3.  **反复听**：双击字幕行进行循环播放。

## ⌨️ 快捷键

您可以在 Obsidian 设置中自定义这些快捷键：

| 默认键 | 功能 |
| :--- | :--- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 上一句 / 下一句 |
| `Shift` + `←` / `→` | 快退 / 快进 5秒 |
| `Ctrl/Cmd` + `I` | 插入当前字幕到笔记 |
| `R` | 开始 / 停止录音 |
