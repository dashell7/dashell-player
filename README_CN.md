# LangPlayer - Obsidian 高级语言学习媒体播放器

[![版本](https://img.shields.io/badge/version-1.0.0-blue.svg)](https://github.com/langplayer/langplayer)
[![许可证](https://img.shields.io/badge/license-0--BSD-green.svg)](LICENSE)

LangPlayer 是一款专为语言学习者设计的强大 Obsidian 插件，提供高级媒体播放、字幕同步、发音评估和词汇管理功能。

[English](README.md) | 简体中文

## ✨ 核心功能

### 🎬 高级媒体播放器
- **YouTube 和本地媒体支持**：播放 YouTube 视频或本地媒体文件（MP4、MP3等）
- **字幕同步**：自动加载和同步字幕（支持 SRT、VTT 格式）
- **单词级高亮**：实时单词高亮，与音频播放完美同步
- **播放速度控制**：调节播放速度（0.5x - 2x），实现舒适学习

### 🔄 学习优化播放
- **单句循环**：重复播放单个句子，集中练习
  - 可配置循环次数（1-10次）
  - 自动播放下一句选项
- **AB 复读**：为任意片段设置自定义循环点
- **一键句子播放**：点击任意字幕即可跳转播放该句
- **上下句导航**：轻松在句子间切换

### 🎤 发音练习
- **语音录制**：一键录制你的发音
- **多种语音识别服务**：
  - OpenAI Whisper（文本匹配评分）
  - Azure 语音服务（专业发音评估）
  - 支持 AssemblyAI
- **详细评分**：
  - 综合发音得分
  - 准确度、流利度和完整度指标
  - 单词级错误检测
  - 可视化对比差异

### 📚 词汇管理
- **点击查词**：点击字幕中的任意单词即可查询
- **Language Learner 集成**：与 obsidian-language-learner 插件无缝集成
- **自动填充例句**：自动从当前字幕填充例句

### 🎨 现代化界面
- **可拖动字幕面板**：灵活布局，可拖动字幕面板
- **自定义样式**：调整字体大小、粗细和行高
- **主题兼容**：适配你的 Obsidian 主题（明暗模式）
- **响应式设计**：简洁现代的界面，专为学习优化

## 🚀 安装方法

### 从 Obsidian 社区插件安装（推荐）
1. 打开 Obsidian 设置
2. 进入 社区插件 → 浏览
3. 搜索 "LangPlayer"
4. 点击安装
5. 启用插件

### 手动安装
1. 从[最新发布](https://github.com/langplayer/langplayer/releases)下载 `main.js`、`manifest.json` 和 `styles.css`
2. 创建文件夹：`你的库/.obsidian/plugins/langplayer/`
3. 将下载的文件复制到该文件夹
4. 重新加载 Obsidian
5. 在 设置 → 社区插件 中启用 LangPlayer

## ⚙️ 配置设置

### 基础配置
1. **打开 LangPlayer**：点击左侧功能区的播放图标或使用命令面板
2. **加载媒体**：输入 YouTube 链接或选择本地媒体文件
3. **加载字幕**：YouTube 视频自动检测字幕，或加载本地 SRT/VTT 文件

### 语音录制设置（可选）
使用发音评估功能需要配置：

#### 选项 1：OpenAI（推荐新手）
1. 从 [OpenAI Platform](https://platform.openai.com/api-keys) 获取 API 密钥
2. 设置 → LangPlayer → 语音服务提供商 → OpenAI
3. 输入你的 API 密钥
4. 点击"测试连接"

#### 选项 2：Azure（专业发音评估）
1. 在 [Azure Portal](https://portal.azure.com) 创建语音服务资源
2. 获取你的订阅密钥和区域
3. 设置 → LangPlayer → 语音服务提供商 → Azure
4. 输入凭据并选择语音
5. 点击"测试连接"

**费用参考**：
- OpenAI：约 $0.006/分钟
- Azure：$1/1000次请求（每月免费 5000 次）

## 📖 使用指南

### 播放媒体
1. **打开播放器**：点击功能区图标或使用命令"打开媒体播放器"
2. **加载内容**：
   - 粘贴 YouTube 链接，或
   - 点击"浏览本地文件"
3. **加载字幕**：YouTube 自动加载，或选择本地 SRT/VTT 文件

### 使用字幕学习
- **点击字幕**：跳转到该句并开始播放
- **循环练习**：点击 🔁 按钮重复当前句子
- **导航**：使用 ⬅️ 上一句 / 下一句 ➡️ 按钮
- **查词**：点击字幕中的任意单词进行词典查询

### 录制发音
1. **选择句子**：点击或导航到一个字幕
2. **开始录音**：点击 🎤 麦克风按钮
3. **朗读**：大声朗读句子
4. **停止并评估**：获得详细评分反馈

### 使用独立字幕面板
1. 命令面板 → "打开字幕面板"
2. 将面板拖到你喜欢的位置（侧边栏、底部等）
3. 在主编辑器中查看媒体的同时保持字幕可见

## ⌨️ 键盘快捷键

你可以在 Obsidian 设置 → 快捷键 中配置：

- **切换播放/暂停**：空格键（播放器聚焦时）
- **上一句**：左箭头
- **下一句**：右箭头
- **切换循环**：L
- **退出循环**：Escape
- **开始录音**：R

## 🎯 使用技巧与最佳实践

### 高效学习方法
1. **使用循环练习**：对困难句子设置 3-5 次循环
2. **启用自动播放下一句**：连续练习多个句子
3. **录制自己的发音**：与原音对比你的发音
4. **降低播放速度**：对有挑战的内容减慢速度
5. **积累词汇**：点击生词创建词汇笔记

### 获得更好性能
1. **使用本地文件**：比 YouTube 流媒体加载更快
2. **匹配字幕时间**：确保字幕与音频匹配以获得准确同步
3. **关闭其他面板**：专注模式，减少干扰

## 🔧 设置参考

### 播放器设置
- **循环次数**：每个句子重复次数（1-10）
- **自动播放下一句**：循环结束后自动播放下一句
- **视频填充模式**：视频如何填充播放器（包含/覆盖/填充）
- **显示内嵌字幕**：在视频下方显示字幕列表（或使用独立面板）

### 字幕样式
- **字体大小**：12-24px（默认：15px）
- **字体粗细**：正常到粗体（默认：500）
- **行高**：1.0-2.5（默认：1.6）

### 语音录制
- **语音服务提供商**：选择 OpenAI、Azure 或 AssemblyAI
- **音频格式**：WAV、WebM 或 MP3
- **保存音频**：可选择将录音保存到库
- **仅录音模式**：跳过转录（用于无反馈练习）

## 📝 支持的格式

### 媒体文件
- 视频：MP4、WebM、OGV
- 音频：MP3、WAV、OGG、M4A、FLAC、AAC
- 流媒体：YouTube 链接

### 字幕文件
- SRT（SubRip）
- VTT（WebVTT）
- 支持双语字幕（英中、英日等）

## 🐛 故障排除

### 找不到麦克风
请查看 设置 → 启用语音转文字 中的诊断步骤

### 字幕不同步
1. 检查字幕文件是否与媒体匹配
2. 在播放器控制中调整字幕偏移
3. 确保字幕文件编码为 UTF-8

### YouTube 播放问题
1. 检查网络连接
2. 验证 YouTube 链接是否有效
3. 尝试使用视频的本地副本

### API 错误
1. 验证 API 密钥正确
2. 检查账户是否有足够的额度/配额
3. 在设置中测试连接
