# LangPlayer 听写功能 — 使用说明

> 听写（Dictation）是 LangPlayer 的核心练习模式：跟着字幕逐句听写英文，对错实时反馈，错的强制留下重来，直到所有字母都打对才能进下一句。

---

## 1. 它适合什么场景

- 你有一段带 SRT/VTT 字幕的英文视频或音频
- 想训练**听辨 + 拼写**而不是泛听
- 准备 BEC / 雅思听写、四六级、专四专八、各类口试拼写抽查
- 不只是"猜个大概"，而是要把每个字母都听清写对

不适合：纯泛听、看懂大意即可的场景（直接看视频更高效）。

---

## 2. 打开方式

需要先打开一个媒体文件，让 LangPlayer 同时显示**播放器**和**字幕面板**。

在字幕面板右上角工具栏找到 **T** 图标（在 EN/中/时间切换按钮的右边），点击即进入听写。再次点击退出。

> 提示：进入听写后，视频上方的双语字幕会自动隐藏（防止偷看），关闭听写后自动恢复。

---

## 3. 核心交互流程

```
打开听写
  ↓
当前句从头自动播放 ──→ 句尾自动暂停
  ↓
你开始打字
  ├── 全部字母都对 ──→ 输入框绿闪 350ms ──→ 自动进下一句继续播放
  └── 有错字母    ──→ 错的格子变红，光标继续前进；你可以
                         ├── 直接 backspace 回去改
                         ├── 按 Space 重听本句
                         ├── 按 Tab 让程序补出当前光标处的正确字母
                         └── 连续打错 N 次后按 Esc 让程序显示整句答案
```

**没有"提交"按钮** — 程序持续监测，每按一键就判定一次；所有格子都正确时自动前进。

---

## 4. 键盘快捷键

| 键 | 作用 | 说明 |
|---|---|---|
| **字母 / 数字 / `'` / `-`** | 填当前格子 | 不区分大小写。错的字符也会被填进去并标红 |
| **Backspace** | 退格 | 删除当前/上一格的字符 |
| **← / →** | 移动光标 | 任意定位到某个格子 |
| **Space** | 重听本句 | 句尾会再次自动暂停 |
| **Tab** | 提示一个字母 | 在光标位置补出正确字母（蓝色）；该句标记为错题；可多次按 |
| **Esc** | 显示整句答案 | **仅在累计错够 N 次后**才生效；显示后该句记为错题，Enter 进下一句 |
| **Enter** | 进下一句 | 仅在"答完正确等待自动前进时"或"已按 Esc 显示答案后"有效 |

**写错了不影响你继续打** — 光标始终前进，你可以打完全句再回头修，也可以立刻 backspace 改。哪种顺手用哪种。

---

## 5. 字母格子的颜色

| 状态 | 外观 | 含义 |
|---|---|---|
| **空** | 灰色下划线，无字 | 还没输入 |
| **当前** | 紫色下划线，闪烁 | 光标在这里，下一个按键会落到这格 |
| **对** | 绿色下划线 | 你打对了 |
| **错** | 红色下划线 + 红字 + 红底 | 你打的字符不匹配 |
| **被提示** | 蓝色下划线 + 蓝字 + 浅蓝底 | Tab 补出来的字母（不算你打对的）|
| **解锁显示** | 浅蓝整片 | Esc 触发后显示的全句答案 |

---

## 6. Tab 提示 vs Esc 显示答案 — 区别在哪

| | **Tab 提示一个字母** | **Esc 显示全句答案** |
|---|---|---|
| 作用范围 | 当前光标所在的**一个**字母 | 整句所有字母 |
| 何时可用 | 任何时候 | 累计错字符数 ≥ 设置的阈值（默认 5）才解锁 |
| 视觉 | 该格变蓝 | 全句变浅蓝高亮 |
| 后续 | 光标前进一格，你继续打 | 主按钮变"下一句"，按 Enter 前进 |
| 错题队列 | 该句加入错题 | 该句加入错题 |
| failCount | **不增加** | 不增加 |
| 适用 | "我就是这一个字母拼不准" | "整句我都没听清，先放过" |

**举例 — necessary 不确定双 c 还是单 c**：
1. 打 `n` `e` `c` → 光标在第 4 格
2. 按 Tab → 第 4 格补出 `c`（蓝色）
3. 接着自己打 `e` `s` `s` `a` `r` `y` → 全绿 → 自动下一句

**举例 — achievement 不确定 ei 还是 ie**：
1. 打 `a` `c` `h` → 光标在第 4 格
2. Tab → 出 `i`（蓝）→ Tab → 出 `e`（蓝）
3. 接着自己打 `v` `e` `m` `e` `n` `t` → 自动下一句

## 7. 进度点与错题队列

面板顶部一长串小圆点，每个点 = 一句：

- **紫色描边的实心点** = 当前句
- **绿色** = 已正确听写
- **红色** = 错题（错过或用过提示）
- **灰色** = 待练

右上角 `12/200` = 当前是第 12 句，共 200 句。

### 错题重练

右上角 **"错题重练"** 按钮：
- 灰色 = 无错题，无需重练
- 可点 = 进入只循环错题模式；所有错题答对后自动退出重练模式
- 已开启 = 显示 ✓，再点退出

---

## 8. 配合"单句循环"按钮

听写期间，播放器工具栏的**单句循环**按钮（旋转箭头图标）仍然可用：

- 默认听写：句尾暂停 → 你打字 → 全对自动下一句
- 开启循环：句尾自动 seek 回句首继续播放 → 你边听边打 → 全对自动下一句，**循环在新句继续生效**
- 右键循环按钮可选循环次数（1/2/3/5/10/20/50/100）

适合长句子或听不清的口音：让音频一直放，你只管打字。

> AB 复读、影子跟读在听写期间不可用（这两个和听写的交互模型不兼容）。

---

## 9. 设置

**设置 → 通用 → 听写**

| 项 | 说明 | 默认 |
|---|---|---|
| 显示答案的失败次数阈值 | 同一句累计敲错多少个字符后，"我放弃了 — 显示答案"链接才出现 | 5（范围 1–20）|

**为什么是字符级而不是句级**：box 模式里每按错一个字母算一次。短句 5 次很容易达到，长句给的容错更多。

---

## 10. 一轮听完之后

跑完所有句子（或在错题重练里清空错题）会进入**完成屏**：

```
全部完成，做得不错。
12/15 正确
[重练错题]   [从头再来]
```

- **重练错题**：错题非空时启用；点击进入错题重练模式，从第一个错题开始
- **从头再来**：清空 checked 标记（保留错题队列），从第 1 句重新开始；适合复习整段

---

## 11. 与录音、AI 等其他模式的关系

- 听写中按麦克风开始录音 → 听写自动暂停（监视器关闭，循环退出）；录音停止后会自动重新装填本句
- 听写中切换字幕源 / 关闭面板 → 状态全部清理；同一媒体的进度会自动保存并在下次恢复
- 听写期间播放器的"上一句 / 下一句"按钮、字幕列表点击都会带着听写跳到对应句

## 12. 常见问题

**Q：键盘按了没反应**
A：通常是焦点丢失。点击一下字符格子区域重新聚焦；按 Tab 或 Space 不行的话试试任意字母键唤醒。

**Q：可以中文听写吗**
A：当前只支持英文（含数字、撇号、连字符）。中文需要单独的拼写引擎，目前不在范围内。

**Q：标点和大小写算错吗**
A：标点自动渲染、不需要打。大小写不敏感（你打 `the` 和 `The` 都对）。

**Q：It's 中的撇号需要自己打吗**
A：需要。撇号是 box 之一，正确打 `i` `t` `'` `s` 4 个字符。

**Q：长句太宽看不全**
A：句子会按词自动换行，每行末尾不会切断单词。如果还是觉得拥挤，调大字幕面板的高度。

**Q：错题队列怎么持久化**
A：已支持自动持久化。按“媒体源 + 字幕指纹”保存；同一份媒体和字幕再次打开会自动恢复。

**Q：可以自定义快捷键吗**
A：当前快捷键写死，不可改。如果你的键位偏好不一样（比如想用 Caps Lock 重听），告诉开发者。

## 13. 推荐使用流程

1. 打开一个 5–15 分钟的英文短视频（YouTube 用 LangPlayer 下载，自带字幕）
2. 开启听写
3. **快速过一遍**：能立刻打对的就打，卡住的按 Tab 补一个字母赶紧过
4. 跑完一轮 → 看错题数，进入错题重练
5. 错题重练时**禁止用 Tab 提示** — 自己硬磕，磕不动按 Esc 看答案
6. 反复几遍直到错题队列清空
7. 第二天再打开同一段做一次（艾宾浩斯，靠记忆复盘）
