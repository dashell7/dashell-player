# Dashell Player 1.9.5 verification

Date: 2026-10-10. This release packages the player UI changes merged in PR #5,
based on commit `11901c6512c5b01e595af92ce0e55d72318a578a`.
Release preparation changes version metadata, documentation, and the locked
development dependencies; it does not add further runtime behavior changes.

## Automated verification

- Clean dependency install: `npm ci --ignore-scripts`.
- TypeScript: `npm run typecheck` passed.
- Tests: `npm test` passed, with 23 test files and 108 tests.
- Production build and packaging: passed. The zip contains only `main.js`,
  `manifest.json`, and `styles.css`.
- Dependency audit: `npm audit` reported 0 known vulnerabilities at check time.
- Local release audit: version, required assets, sizes, and hashes passed.

The repository CI repeats clean installation, type checking, tests, and the
production build on Ubuntu with Node.js 20 and 22.

## Desktop host verification

The candidate was installed and reloaded in the user-designated test vault on
desktop Obsidian 1.12.4. The scripted controls and practice checks passed all
18 assertions, with no captured runtime errors during those checks:

- Local video and audio play and automatically load matching subtitle files.
- The duplicate Obsidian view header is hidden.
- The four subtitle controls remain available during playback and pause.
- Hiding the current sentence preserves its action buttons.
- Detached and inline transcripts are mutually exclusive. Manually closing the
  detached pane updates the corresponding switch.
- Actual pointer dragging and keyboard resizing work for the pane dividers.
- Study modes retain independent pane sizes after closing and reopening.
- Dictation accepts keyboard input; reference subtitles can be shown and hidden
  repeatedly, and advancing to the next sentence hides them again.
- The toolbar and dictation layouts fit tested pane widths of 1000, 720, 390,
  and 320 px without horizontal overflow. The dark narrow layout was also
  visually checked.

Test fixtures were removed and the original settings, layout preferences, and
open media were restored. The tested candidate remains installed. Private
vault records, backup files, and screenshots are excluded from the repository
and release assets.

## Coverage limits and distribution

Physical iOS/Android devices, actual microphone recording, all media codecs,
and a fresh empty-vault installation were not tested in this round. Narrow
desktop panes are layout checks, not mobile-device validation.

This is a GitHub-only release. The user requested skipping the Obsidian official
preview scan; no official review or community-directory availability is claimed.
Release publication additionally verifies the uploaded assets and their public,
unauthenticated download URLs before updating the default branch's version.
